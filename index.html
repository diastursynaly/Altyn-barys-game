Формулалар

n = m / M  ·  n = V / 22,4 (газ, қ.ж.)
ω = m(зат) / m(ерітінді немесе қоспа)
C = n / V(ерітінді, л)
M = 2 · D(H2)
Жану өнімдері бойынша: n(C) = n(CO2), n(H) = 2 · n(H2O), m(O) = m(зат) − m(C) − m(H)

Металдар

  • Мырыш тұз қышқылынан сутекті ығыстырады, мыс пен алтын ығыстырмайды.
  • Жез: мыс пен мырыштың құймасы.
